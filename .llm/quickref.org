* 📝 Common Code Patterns

** Basic DOM Manipulation

#+begin_src elixir
defmodule MyApp do
  alias CurupiraWeb.DOM

  def main do
    # Query elements
    {:ok, app} = DOM.query_selector("#app")

    # Create elements
    {:ok, button} = DOM.create_element("button")
    button = DOM.set_inner_text(button, "Click me!")
    button = DOM.add_class(button, "btn-primary")

    # Add event handlers
    button = DOM.on_click(button, fn event ->
      DOM.prevent_default(event)
      IO.puts("Button clicked!")
    end)

    # Append to DOM
    DOM.append_child(app, button)
  end
end
#+end_src

** FFI (Calling JavaScript)

#+begin_src elixir
defmodule MyApp.Console do
  use CurupiraJS.FFI

  # Call existing JS function
  ffi :log,
    js_path: "console.log",
    args: [:any],
    returns: :ok

  # Custom JS code
  ffi :greet,
    args: [:string],
    returns: :string,
    js: """
    (name) => {
      return `Hello, ${name}!`;
    }
    """

  # With struct wrapper
  ffi :query_element,
    args: [:string],
    returns: {:option, MyElement.t()},
    wrapper: true,
    js: """
    (selector) => {
      const el = document.querySelector(selector);
      if (!el) return null;
      return {
        id: el.id,
        __ref__: el
      };
    }
    """
end
#+end_src

** HTTP Requests

#+begin_src elixir
defmodule MyApp.API do
  alias CurupiraJS.HTTP

  def fetch_users do
    case HTTP.get("https://api.example.com/users") do
      {:ok, response} ->
        IO.inspect(response.status)
        IO.inspect(response.body)
        {:ok, response}

      {:error, reason} ->
        IO.puts("Request failed: #{reason}")
        {:error, reason}
    end
  end

  def create_user(data) do
    HTTP.post("https://api.example.com/users",
      body: JSON.encode!(data),
      headers: %{"Content-Type" => "application/json"}
    )
  end
end
#+end_src

* 🏛️ Architecture

** Compilation Flow

#+begin_example
User's .ex files
    ↓
mix compile (triggers curupira_js compiler)
    ↓
List.wrap entry modules
    ↓
DependencyWalker (find all used modules)
    ↓
Extract BEAM debug_info (abstract_code)
    ↓
Compiler.compile (each module)
    ↓
Translator (Elixir AST → ESTree)
    ↓
ESTree.encode (ESTree → JavaScript string)
    ↓
Bundler (combine into single file)
    ↓
Write to output file (priv/static/js/app.js)
#+end_example

* 🐛 Troubleshooting

** Tests Failing

#+begin_src shell
# Run single test
mix test test/file_test.exs:42

# Clean and recompile
mix clean && mix compile

# Check Elixir version (need 1.17+)
elixir --version
#+end_src

** Compilation Errors

Common issues:
- Missing dependencies: =mix deps.get=
- Stale build: =mix clean=
- Wrong Elixir version: Need 1.17+

** JavaScript Output Issues

1. Check translator.ex for that Elixir construct
2. Look at generated bundle (output file)
3. Add IO.inspect to debug Elixir values
4. Write a minimal test case
