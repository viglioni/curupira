* Primary Goal

Write frontend applications in *pure Elixir* - zero JavaScript required.

User writes Elixir, Curupira handles all the JavaScript transpilation and browser API wrapping.

* Core Philosophy

** Write Only Elixir

#+begin_src elixir
# User writes this - pure Elixir
defmodule MyApp do
  alias CurupiraWeb.{Document, Element}

  def main do
    Document.get_element_by_id("app")
    |> Element.set_text("Hello from Elixir!")
    |> Element.add_class("active")
  end
end
#+end_src

#+begin_src javascript

** Everything Returns Elixir Structs

Critical: Browser APIs must return Elixir structs, not raw JS objects.

*** Bad (Raw JS):
#+begin_src elixir
# Returns raw JS object - can't pattern match!
elem = Document.get_element_by_id("foo")
# What is elem? Unknown shape!
#+end_src

*** Good (Elixir Structs):
#+begin_src elixir
# Returns proper Elixir struct
%Element{id: "foo", tag_name: "div", class_list: classes} =
  Document.get_element_by_id("foo")

# Can pattern match!
def handle_element(%Element{tag_name: "button"} = btn) do
  Element.set_disabled(btn, true)
end

# Can pipe!
Document.get_element_by_id("submit")
|> Element.set_text("Click me")
|> Element.add_class("btn-primary")
|> Element.add_event_listener("click", &handle_click/1)
#+end_src

* Package Responsibilities

** curupira_script (Core Transpiler)

*Purpose:* Compile Elixir → JavaScript

*Must Support:*

*** Structs (CRITICAL!)

#+begin_src elixir
defmodule User do
  defstruct [:name, :age, :email]
end

%User{name: "Alice", age: 30, email: "alice@example.com"}
#+end_src

Compiles to:
#+begin_src javascript
class User {
  constructor(fields = {}) {
    this.__struct__ = Symbol.for("Elixir.User");
    this.name = fields.name ?? null;
    this.age = fields.age ?? null;
    this.email = fields.email ?? null;
    Object.freeze(this);
  }
}

new User({name: "Alice", age: 30, email: "alice@example.com"})
#+end_src

*** Pattern Matching on Structs

#+begin_src elixir
def greet(%User{name: name, age: age}) when age >= 18 do
  "Hello, #{name}!"
end
#+end_src

*** Pipe Operator

#+begin_src elixir
data
|> transform()
|> validate()
|> save()
#+end_src

*** All Basic Types

- Atoms, strings, integers, floats
- Lists, maps, tuples
- Structs
- Comprehensions
- Guards

*** NOT Supporting

- ❌ Macros (use pre-expanded AST)
- ❌ Protocols (maybe later)
- ❌ OTP (GenServer, etc.)
- ❌ Processes (spawn/receive)

* Real-World Example: Todo App

#+begin_src elixir
defmodule TodoApp do
  @moduledoc """
  Complete TodoMVC implementation in pure Elixir
  """

  alias CurupiraWeb.{Document, Element, Event, Storage, Console}

  defmodule Todo do
    defstruct [:id, :text, :completed]
  end

  def main do
    Console.log("Todo app starting...")

    # Setup event listeners
    Document.get_element_by_id("add-btn")
    |> Element.add_event_listener("click", &handle_add/1)

    Document.get_element_by_id("clear-completed")
    |> Element.add_event_listener("click", &handle_clear_completed/1)

    # Load and render initial todos
    load_todos()
    |> render_todos()
  end

  # Event Handlers

  defp handle_add(%Event{} = event) do
    Event.prevent_default(event)

    input = Document.get_element_by_id("todo-input")

    case Element.get_value(input) do
      "" ->
        :ok
      text ->
        new_todo = %Todo{
          id: generate_id(),
          text: text,
          completed: false
        }

        todos = [new_todo | load_todos()]

        save_todos(todos)
        render_todos(todos)
        Element.set_value(input, "")
    end
  end

  defp handle_toggle(%Event{target: target}) do
    %Element{attributes: attrs} = target
    todo_id = Map.get(attrs, "data-id") |> String.to_integer()

    todos = load_todos()
    |> Enum.map(fn
      %Todo{id: ^todo_id} = todo ->
        %{todo | completed: !todo.completed}
      todo ->
        todo
    end)

    save_todos(todos)
    render_todos(todos)
  end

  defp handle_clear_completed(_event) do
    todos = load_todos()
    |> Enum.reject(&(&1.completed))

    save_todos(todos)
    render_todos(todos)
  end

  # Rendering

  defp render_todos(todos) do
    container = Document.get_element_by_id("todo-list")

    # Clear existing
    Element.set_inner_html(container, "")

    # Render each todo
    Enum.each(todos, fn todo ->
      render_todo(todo)
      |> Element.append_to(container)
    end)

    update_counts(todos)
  end

  defp render_todo(%Todo{id: id, text: text, completed: completed}) do
    li = Document.create_element("li")
    |> Element.add_class(if completed, do: "completed", else: "")

    checkbox = Document.create_element("input")
    |> Element.set_attribute("type", "checkbox")
    |> Element.set_attribute("data-id", to_string(id))
    |> Element.set_checked(completed)
    |> Element.add_event_listener("change", &handle_toggle/1)

    label = Document.create_element("label")
    |> Element.set_text(text)

    li
    |> Element.append_child(checkbox)
    |> Element.append_child(label)
  end

  defp update_counts(todos) do
    active_count = Enum.count(todos, &(!&1.completed))
    completed_count = Enum.count(todos, &(&1.completed))

    Document.get_element_by_id("active-count")
    |> Element.set_text("#{active_count} items left")

    Document.get_element_by_id("clear-completed")
    |> Element.set_text("Clear completed (#{completed_count})")
    |> Element.set_visible(completed_count > 0)
  end

  # Storage

  defp load_todos do
    case Storage.get("todos") do
      nil -> []
      json -> JSON.decode!(json)
    end
  end

  defp save_todos(todos) do
    Storage.set("todos", JSON.encode!(todos))
  end

  defp generate_id do
    :rand.uniform(1_000_000)
  end
end
#+end_src

* Critical Requirements

** For curupira_script

1. *Struct support* - MUST WORK
   - Define structs
   - Pattern match on structs
   - Update structs (=%{user | name: "Bob"}=)

2. *Pattern matching* - MUST WORK
   - Function heads
   - Case expressions
   - With expressions
   - Guards

3. *Pipe operator* - MUST WORK
   - Chain transformations
   - Works with structs

4. *Modern Elixir* - SHOULD WORK
   - Stepped ranges
   - =then/2=, =tap/2=
   - Duration
   - JSON module

** For curupira_web

1. *Everything returns structs* - CRITICAL
   - =Document.get_element_by_id/1= → =Element.t()=
   - Event handlers receive =Event.t()=
   - Fetch returns =Response.t()=

2. *Pipeable API* - CRITICAL
   #+begin_src elixir
   elem
   |> Element.set_text("foo")
   |> Element.add_class("bar")
   #+end_src

3. *Pattern matchable* - CRITICAL
   #+begin_src elixir
   def handle(%Event{type: "click", target: target}) do
     # ...
   end
   #+end_src

4. *Feels like Elixir* - CRITICAL
   - Use Elixir conventions
   - Return ={:ok, value}= or ={:error, reason}=
   - Use atoms for tags
   - Use keyword lists for options

* Non-Requirements

** Don't Need

- Full OTP support
- Processes (spawn/receive)
- GenServer/Supervisor
- Distributed Erlang
- NIFs/Ports
- 100% stdlib coverage

** Can Live Without

- Macros (use pre-expanded AST)
- Protocols (maybe later)
- Some stdlib functions
- Full Unicode support

* Performance Targets

** Compilation Speed

| Project Size | Target |
|--------------|--------|
| Small (10 modules) | < 2s |
| Medium (50 modules) | < 5s |
| Large (100 modules) | < 15s |

Watch mode: < 500ms for single module

** Bundle Size (minified + gzipped)

| App Complexity | Target |
|----------------|--------|
| Small (basic DOM) | ~25 KB |
| Medium (+ fetch, storage) | ~50 KB |
| Large (full features) | ~100 KB |

** Runtime Performance

Fast enough for UI interactions:
- Button clicks: instant
- List rendering (1000 items): < 100ms
- Form validation: instant
- API calls: network-bound

Don't need to beat React/Vue, just be usable.

* Philosophy

Write frontend apps the same way you write Elixir backend:
- Structs for data
- Pattern matching for flow control
- Pipes for transformations
- Comprehensions for collections
- Guards for validation
