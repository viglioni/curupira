* Reading Order for New Sessions

1. *First time ever:* Read all files in order
   - =claude.md= (30 min)
   - =design.org= (45 min)
   - =decisions.org= (30 min)
   - =quickref.org= (15 min)

2. *Starting new session:* Quick refresh
   - =claude.md= - Skim "Current Priority" section
   - =quickref.org= - Check current status
   - Ask user what to work on

3. *During work:* Reference as needed
   - =design.org= - For implementation details
   - =decisions.org= - For "why" questions
   - =quickref.org= - For quick lookups

* Updating These Files

** When to Update

Update these files when:
- Project status changes (new phase)
- Major decisions are made
- Architecture changes
- New features added
- After completing milestones

** Who Updates

- Developers working on Curupira
- Claude Code (when prompted)
- Tech lead reviewing changes

** How to Update

1. Edit the relevant =.org= or =.md= file
2. Update "Last Updated" date
3. Keep changes concise
4. Commit with descriptive message

Example:
#+begin_src shell
git add .llm/
git commit -m "docs: update context files after Phase 0 completion"
#+end_src
