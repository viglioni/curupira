* Notes

** What to Steal from ElixirScript

Don't reinvent these:
- Pattern matching library (Tailored) - too complex
- Type definitions (Tuple, BitString) - working well
- Test suite - validate behavior
- Trampolining implementation - solved problem

** What to Build Fresh

Better to rebuild:
- Compiler pipeline (cleaner with modern Elixir)
- Mix integration (modern =Mix.Task.Compiler=)
- AST translation (can be cleaner)
- Stdlib implementations (modern JS)
