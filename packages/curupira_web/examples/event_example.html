CurupiraWeb Event Handling Examples

These examples demonstrate event handling compiled from Elixir to JavaScript using CurupiraWeb.

1. Click Counter

Click the button to increment the counter.

2. Input Logger

Type your name to see it reflected below.

3. Form Submission

Submit the form to see preventDefault in action.

4. Keyboard Events

Press Ctrl+Enter to submit your search query.

5. Mouse Hover

Hover over the box to see the effect.

Hover over me!

6. Focus/Blur Validation

Enter a username (min 3 characters). Validation happens on blur.

⚠️ To run this example:

  1. Compile the Elixir code to JavaScript
  2. Uncomment the script tags above
  3. Open this HTML file in a browser

Compile command:
mix curupira_js.build --input CurupiraWeb.Examples.EventExample --output examples/event_example.js
