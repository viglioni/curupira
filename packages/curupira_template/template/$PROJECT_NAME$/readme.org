A client-side application built with *CurupiraJS* - compile Elixir to JavaScript!

* Getting Started

** Installation

First, install dependencies:

#+begin_src shell
  mix deps.get
#+end_src

** Building

Compile your Elixir code to JavaScript:

#+begin_src shell
  mix curupira_js.build
#+end_src

This will compile your Elixir modules into =priv/static/js/app.js=

** Development

For development with automatic recompilation on file changes:

#+begin_src shell
  mix curupira_js.watch
#+end_src

Then open =html/index.html= in your browser (you can use a simple HTTP server):

#+begin_src shell
  # Using Python
  python3 -m http.server 8000
  # Then visit http://localhost:8000/html/

  # Or using Node.js
  npx http-server -p 8000
  # Then visit http://localhost:8000/html/
#+end_src

* Project Structure

* How It Works

1. Write Elixir code using =CurupiraWeb.DOM= for DOM manipulation
2. Compile with =mix curupira_js.build=
3. Your Elixir code is transpiled to JavaScript
4. The =<%= @project_name_camel_case %>.main()= function is called when the page loads

* DOM Manipulation

Use =CurupiraWeb.DOM= to interact with the browser:

#+begin_src elixir
  alias CurupiraWeb.DOM

  # Query elements
  {:ok, element} = DOM.query_selector("#app")

  # Create elements
  {:ok, button} = DOM.create_element("button")
  button = DOM.set_inner_text(button, "Click me!")

  # Add event listeners
  button = DOM.on_click(button, fn event ->
    IO.puts("Clicked!")
  end)

  # Append to DOM
  element = DOM.append_child(element, button)
#+end_src
