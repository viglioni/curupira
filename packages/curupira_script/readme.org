* CurupiraScript

Elixir to JavaScript transpiler for client-side applications.

Modern fork of [[https://github.com/elixirscript/elixirscript][ElixirScript]] supporting Elixir 1.17+.

** Status

🚧 *Under Development* - Phase 0: Architecture Study

Currently studying ElixirScript architecture to build fresh implementation.

** What is CurupiraScript?

Compiles Elixir code to JavaScript, allowing you to write client-side web applications in Elixir.

#+begin_src elixir
# Write Elixir
defmodule MyApp do
  def greet(name) do
    "Hello, #{name}!"
  end
end
#+end_src

#+begin_src javascript
// Get JavaScript
export default {
  greet(name) {
    return `Hello, ${name}!`;
  }
};
#+end_src

** Installation

Add to your =mix.exs=:

#+begin_src elixir
def deps do
  [
    {:curupira_script, "~> 0.33"}
  ]
end
#+end_src

** Configuration

#+begin_src elixir
# mix.exs
def project do
  [
    compilers: Mix.compilers() ++ [:curupira_script],
    curupira_script: [
      input: MyApp,
      output: "assets/js"
    ]
  ]
end
#+end_src

** Usage

#+begin_src shell
mix compile
#+end_src

Generated files will be in =assets/js/Elixir.MyApp.js=

** Features

*** Supported ✅

- Basic data types (integers, floats, strings, atoms, lists, maps, tuples)
- *Structs* (CRITICAL for DOM APIs)
- Functions with pattern matching and guards
- Pipe operator
- Comprehensions
- Control flow (if, case, cond, with)

*** Planned 🚧

- Stepped ranges (=1..10//2=)
- =then/2= and =tap/2=
- Duration type
- JSON module
- Expanded stdlib

*** Not Supported ❌

- GenServer, Supervisor (no OTP)
- spawn, send, receive (no processes)
- Macros (use pre-expanded AST)
