* CurupiraScript

Elixir to JavaScript transpiler for client-side applications.

Modern fork of [[https://github.com/elixirscript/elixirscript][ElixirScript]] supporting Elixir 1.17+.

** Status

✅ *Core Implementation Complete*

- JavaScript bundler with dependency walking
- Verified working in Node.js 18+

** What is CurupiraScript?

Compiles Elixir code to JavaScript, allowing you to write client-side web applications in Elixir.

#+begin_src elixir
# Write Elixir
defmodule MyApp.Site do
  def main do
    greet("World")
  end

  def greet(name) do
    "Hello, #{name}!"
  end
end
#+end_src

#+begin_src javascript
// Use in JavaScript
import MyApp from './js/elixir_bundle.js';

MyApp.Site.main();  // "Hello, World!"
#+end_src

** Configuration

In your =mix.exs=:

#+begin_src elixir
def project do
  [
    app: :my_app,
    # ...other config...

    # CurupiraScript configuration
    curupira_js: [
      input: [MyApp.Site, MyApp.Helper],  # Entry modules
      output: "js/elixir_bundle.js"       # Output path (default)
    ]
  ]
end
#+end_src

*** Bundle structure

The generated bundle has nested namespaces matching your module structure:

** Architecture

*** Compilation Pipeline

1. *Entry Modules*: Start with configured =input= modules
2. *Dependency Walking*: Recursively find all called modules
3. *BEAM Reading*: Extract AST from compiled BEAM files
4. *Translation*: Convert Elixir AST to JavaScript (ESTree)
5. *Code Generation*: Generate JavaScript code
6. *Bundling*: Combine into single file with nested structure
7. *Output*: Write to configured =output= path

*** Module Mapping

Elixir modules map to nested JavaScript objects:

| Elixir               | JavaScript          |
|----------------------+---------------------|
| =MyApp.Site=         | =MyApp.Site=        |
| =MyApp.Site.Auth=    | =MyApp.Site.Auth=   |
| =MyApp.Utils.Format= | =MyApp.Utils.Format= |

*** Type Mapping

| Elixir Type | JavaScript Type                              |
|-------------+----------------------------------------------|
| Integer     | =number=                                     |
| Float       | =number=                                     |
| String      | =string=                                     |
| Atom        | =Symbol.for("atom_name")=                    |
| List        | =Array= (frozen with =Object.freeze=)        |
| Tuple       | ={__tuple__: true, values: [...]}=           |
| Map         | =Object= or =Map= (keyword lists)            |
| Struct      | =class= with =__struct__= field              |

** Examples

*** Basic Usage

#+begin_src elixir
# lib/my_app/site.ex
defmodule MyApp.Site do
  def main do
    message = greet("World")
    format_message(message)
  end

  defp greet(name) do
    "Hello, #{name}!"
  end

  defp format_message(msg) do
    String.upcase(msg)
  end
end
#+end_src

#+begin_src javascript
// app.js
import MyApp from './js/elixir_bundle.js';

console.log(MyApp.Site.main());  // "HELLO, WORLD!"
#+end_src

*** With HTTP Client

#+begin_src elixir
defmodule MyApp.API do
  def fetch_users do
    case HTTP.get("https://api.example.com/users") do
      {:ok, response} -> response.body
      {:error, reason} -> "Error: #{reason}"
    end
  end
end
#+end_src

*** With JSON

#+begin_src elixir
defmodule MyApp.Data do
  def encode_user(name, age) do
    data = %{name: name, age: age}
    JSON.encode!(data)
  end

  def decode_user(json) do
    case JSON.decode(json) do
      {:ok, data} -> data
      {:error, _} -> %{}
    end
  end
end
#+end_src

*** With Pattern Matching

#+begin_src elixir
defmodule MyApp.Parser do
  def parse_response({:ok, %{status: 200, body: body}}), do: {:success, body}
  def parse_response({:ok, %{status: code}}), do: {:error, code}
  def parse_response({:error, reason}), do: {:error, reason}
end
#+end_src

** Limitations

*** Not Supported

- *OTP*: No GenServer, Supervisor, or other OTP primitives
- *Processes*: No =spawn=, =send=, =receive=
- *Macros*: Uses pre-expanded AST only
- *Module Attributes*: Not yet implemented
- *Protocols*: Not yet implemented

*** Performance

- String interpolation uses concatenation (=+=) instead of template literals
- All lists are frozen with =Object.freeze()= for immutability
- Pattern matching uses runtime checks (not as fast as native)
