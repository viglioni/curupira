* CurupiraScript

Elixir to JavaScript transpiler for client-side applications.

Modern fork of [[https://github.com/elixirscript/elixirscript][ElixirScript]] supporting Elixir 1.17+.

** Status

✅ *Core Implementation Complete* - Phases 1-3 Done

Fully functional Elixir to JavaScript transpiler with modern Elixir support.

*Test Coverage:* 97 tests passing, 1 skipped (format option)

** What is CurupiraScript?

Compiles Elixir code to JavaScript, allowing you to write client-side web applications in Elixir.

#+begin_src elixir
# Write Elixir
defmodule MyApp do
  def greet(name) do
    "Hello, #{name}!"
  end
end
#+end_src

#+begin_src javascript
// Get JavaScript
export default {
  greet(name) {
    return `Hello, ${name}!`;
  }
};
#+end_src

** Installation

Add to your =mix.exs=:

#+begin_src elixir
def deps do
  [
    {:curupira_script, "~> 0.33"}
  ]
end
#+end_src

** Configuration

#+begin_src elixir
# mix.exs
def project do
  [
    compilers: Mix.compilers() ++ [:curupira_script],
    curupira_script: [
      input: MyApp,
      output: "assets/js"
    ]
  ]
end
#+end_src

** Usage

#+begin_src shell
mix compile
#+end_src

Generated files will be in =assets/js/Elixir.MyApp.js=

** Features

*** Supported ✅

*Core Language Features:*
- Basic data types (integers, floats, strings, atoms, lists, maps, tuples)
- *Structs* (including TypedStruct support)
- Functions with pattern matching and guards
- Pipe operator
- Control flow (if, case, cond, with)

*Modern Elixir (1.12-1.18):*
- Stepped ranges (=1..10//2=)
- =then/2= and =tap/2= pipeline helpers
- =is_non_struct_map/1= guard
- Duration type (all time units)

*Standard Library (Runtime):*
- JSON module (encode/decode with options)
- HTTP client (fetch-based, async/await)
- Enum functions (50+ functions)
- String functions (40+ functions with Unicode support)
- Map functions (30+ functions)

*** Planned 🚧

- Additional stdlib functions
- Process/GenServer simulation (optional)
- Module attributes
- File I/O adapters

*** Not Supported ❌

- GenServer, Supervisor (no OTP)
- spawn, send, receive (no processes)
- Macros (use pre-expanded AST)
