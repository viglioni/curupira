* About

Build client-side web applications with Elixir.

Curupira is a monorepo containing tools for writing frontend applications in Elixir that compile to JavaScript.

* Packages

** curupira_script

Elixir-to-JavaScript transpiler. Modern fork of ElixirScript with support for Elixir 1.17+.

#+begin_src elixir
# Write Elixir
defmodule MyApp do
  def greet(name), do: "Hello, #{name}!"
end
#+end_src

#+begin_src javascript
// Get JavaScript
export default {
  greet(name) { return `Hello, ${name}!`; }
};
#+end_src

- Status: 🚧 Under development
- Version: 0.33.0-dev
- Location: [[file:packages/curupira_script/][packages/curupira_script/]]

** curupira_web

Web APIs and browser integrations for CurupiraScript.

#+begin_src elixir
# Browser APIs in Elixir
Console.log("Hello from Elixir!")
Document.query_selector("#app")
#+end_src

- Status: 🚧 Planned
- Version: 0.3.0-dev
- Location: [[file:packages/curupira_web/][packages/curupira_web/]]

** curupira_template

Mix template for quickly scaffolding new Curupira projects.

#+begin_src shell
mix gen curupira my_app
cd my_app
mix watch.compile
#+end_src

- Status: ✅ Working (uses ElixirScript 0.32)
- Version: 1.0.0
- Location: [[file:packages/curupira_template/][packages/curupira_template/]]

* Quick Start

** Install Template Generator

#+begin_src shell
mix archive.install hex mix_templates
mix archive.install hex mix_generator
#+end_src

** Create New Project

#+begin_src shell
# Clone this repo
git clone https://github.com/your-org/curupira.git
cd curupira/packages/curupira_template

# Install the template
mix template.install

# Generate a new project
cd ~/projects
mix gen curupira my_app
cd my_app

# Install dependencies
mix deps.get
npm install

# Start development server
mix watch.compile
#+end_src

Your app will be available at http://localhost:5050

* FAQ

** Why Curupira instead of ElixirScript?

ElixirScript hasn't been updated since 2018 and doesn't support modern Elixir features. Curupira is actively maintained and targets Elixir 1.17+.

** Why not Phoenix LiveView?

LiveView is server-rendered. Curupira is for client-side SPAs that run entirely in the browser. Different use cases!

** Can I use this in production?

Not yet! We're in active development. The template works but uses old ElixirScript. Wait for curupira_script v0.33+.

** Does this support React/Vue/etc?

Not out of the box, but you can integrate. We'll provide examples and bindings in the future.

** What about TypeScript definitions?

Planned! We'll generate =.d.ts= files from Elixir =@spec= annotations.
